Project Name: City Pet Dragon
Description: This is a pet simulator based on raising a dragon in a city apartment
Purpose: It's meant to be a simple game to be played occasionally from time to time
Features: Day night cycle based on the system clock, save load features for returning to the game, a few minigames to up the pet's meters
Technologies: Javascript, HTML
AI Tools used: Copilot, Google Gemini
Installation: Download all of the files
Running the Application: Run index.html
How AI was used: Mostly github copilot, Prompts:
Main Prompt - Please make a browser based pet raising game about raising a dragon in an apartment in a city

Features:
Save and load features that saves the state of the pet for future sessions
The environment should look different based on the system clock, windows should show a day night cycle
The dragon should have a food, water, play, and care meters, with feeding them, giving them water, playing with them, and grooming them being the ways to replenish them
The dragon should grow and have some acknoledgement of time passed
